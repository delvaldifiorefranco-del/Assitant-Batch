Displaying drivers, Create directories, open the CMD and theres even a countdown all coded in batch (not made by me). This project is pretty lame because you 
wouldn't need such a program to do these kind of tasks. So, im asking to try and make Assistant an actually useful thing that can make even the most complex
things the easiest ones.
